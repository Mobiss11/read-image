# read-image

> Скриншоты и изображения из чата — анализ одним движением. Скилл для AI-ассистентов: OpenCode, Claude Code, Cursor.

Скилл автоматически извлекает картинки из базы чата (даже несколько в одном сообщении) и анализирует их через: **MiniMax MCP**, **OpenRouter**, **Ollama**, или нативный multimodal. Если провайдера нет — проводит пользователя за руку через настройку.

---

## Что умеет

- Извлекает изображения из чата OpenCode / Claude Code / Cursor
- Поддерживает несколько скриншотов в одном сообщении
- Анализирует через MiniMax, OpenRouter, Ollama, или напрямую (multimodal)
- Автоопределяет IDE и доступные провайдеры
- Встроенный Setup Wizard — если ничего не настроено, ведёт пользователя шаг за шагом

## Быстрый старт

Установи скилл в свой AI-ассистент. Выбери инструмент:

| Инструмент | Как установить |
|---|---|
| **OpenCode** | Скопируй папку `read-image/` в `~/.config/opencode/skills/` |
| **Claude Code** | `/install-skill` → укажи путь к `SKILL.md` |
| **Cursor** | Settings → Features → Skills → Add folder → укажи `read-image/` |

После установки — просто вставь скриншот в чат и скажи:

> *«прочитай скриншот»* или *«что на картинке»* или *«read image»*

## Provider-агностик

Скилл сам выберет лучший доступный способ анализа:

| # | Провайдер | Что нужно | Скорость настройки |
|---|-----------|-----------|-------------------|
| 1 | **MiniMax MCP** | Ничего (встроен в OpenCode) | 0 сек |
| 2 | **OpenRouter** | Бесплатный API-ключ с [openrouter.ai](https://openrouter.ai) | ~2 мин |
| 3 | **Ollama** | `brew install ollama && ollama pull llava:13b` | ~5 мин |
| 4 | **Native multimodal** | Ничего (Claude/GPT сами видят картинки) | 0 сек |

Если ничего не настроено — скилл проведёт через настройку: даст точные команды, подождёт ответа, проверит что заработало.

## Структура

```
read-image/
├── SKILL.md                 ← главный файл скилла (frontmatter + знания)
├── README.md                ← ты здесь
└── scripts/
    ├── extract_images.py    ← извлечение из OpenCode / Claude Code / Cursor
    └── analyze_image.py     ← анализ через OpenRouter / Ollama
```

## Зависимости

- **Python 3.10+** (для скриптов извлечения и анализа)
- **OpenRouter API ключ** — если выбираешь этот провайдер (бесплатно)
- **Ollama** — если выбираешь локальный провайдер (бесплатно)
